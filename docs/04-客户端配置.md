# 客户端配置指南

> 让你的所有 AI 工具都指向 New-API
> 一个 base_url，所有模型可用

---

## 准备工作

1. New-API 已部署并配置 HTTPS（参见 [02-部署指南.md](02-部署指南.md)）
2. 后台已添加至少一个上游渠道（参见 [03-上游接入.md](03-上游接入.md)）
3. 已创建一个 API Token（后台 → **令牌管理** → 添加令牌）

**Token 看起来像**：`sk-xxxxxxxxxxxxxxxxxxxxxxxx`

---

## 一、桌面客户端

### 1.1 ChatBox（最简单，推荐）

跨平台桌面应用，支持所有平台。

**下载地址**：https://github.com/chenchenyang/ChatBox/releases

**配置**：
1. 设置 → **AI Provider** → 选 **Custom Provider**
2. 填入：

| 字段 | 值 |
|------|-----|
| API Host | `https://api.你的域名.com/v1` |
| API Key | New-API 生成的 token |
| Model | 选你要的（如 `gpt-4o-mini`、`deepseek-chat`） |

3. 保存 → 开始对话

---

### 1.2 LobeChat（更强大）

Web + 桌面 + 移动端，开源 AI 聊天框架。

**部署方式（推荐 Docker）**：

在 VPS 上：

```bash
docker run -d \
  --name lobe-chat \
  -p 3210:3210 \
  -e OPENAI_API_URL=https://api.你的域名.com/v1 \
  -e OPENAI_API_KEY=你的New-API_Token \
  --restart always \
  lobehub/lobe-chat
```

访问 `http://你的VPS_IP:3210` 开始用。

**本地配置（如果用 LobeChat 桌面版）**：

设置 → 模型服务 → **OpenAI**：
- API 代理地址：`https://api.你的域名.com/v1`
- API Key：New-API Token

## 二、命令行工具

### 2.1 Python OpenAI SDK

所有官方 SDK 都兼容 OpenAI 格式，所以 New-API 100% 兼容。

```python
from openai import OpenAI

client = OpenAI(
    base_url="https://api.你的域名.com/v1",  # 替换
    api_key="sk-你的New-API-Token"             # 替换
)

response = client.chat.completions.create(
    model="deepseek-chat",  # 或任何 New-API 支持的模型
    messages=[{"role": "user", "content": "你好"}]
)
print(response.choices[0].message.content)
```

### 2.2 Node.js OpenAI SDK

```javascript
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://api.你的域名.com/v1",
  apiKey: "sk-你的New-API-Token",
});

const response = await client.chat.completions.create({
  model: "gpt-4o-mini",
  messages: [{ role: "user", content: "你好" }],
});
console.log(response.choices[0].message.content);
```

### 2.3 curl 测试

```bash
curl https://api.你的域名.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-你的New-API-Token" \
  -d '{
    "model": "deepseek-chat",
    "messages": [{"role": "user", "content": "你好"}]
  }'
```

## 三、IDE 集成（Cursor / Cline / Continue）

### 3.1 Cursor

`Cursor` → Settings → Models → **OpenAI API Key**

- API Key：填 New-API Token
- Override OpenAI Base URL：`https://api.你的域名.com/v1`

### 3.2 VS Code + Cline

VS Code → Extensions → 装 **Cline** → 配置：

设置 → Cline → API Provider：
- Provider: **OpenAI Compatible**
- Base URL: `https://api.你的域名.com/v1`
- API Key: New-API Token
- Model ID: `claude-sonnet-4.5`（或你想要的）

### 3.3 VS Code + Continue

`~/.continue/config.json`：

```json
{
  "models": [
    {
      "title": "New-API",
      "provider": "openai",
      "model": "gpt-4o-mini",
      "apiBase": "https://api.你的域名.com/v1",
      "apiKey": "sk-你的New-API-Token"
    }
  ]
}
```

## 六、订阅链接（多客户端同步）

如果你在多个设备用同一份配置，可以让 New-API 生成**订阅链接**：

后台 → **系统设置** → **订阅设置** → 启用

订阅地址形如：`https://api.你的域名.com/sub?token=xxx`

在 Clash Verge Rev / Shadowrocket 等客户端导入这个链接，自动同步所有节点配置。

## 七、模型选择策略

New-API 里所有模型都是**同一套 API**，调用方法一样。

**推荐用法**：

| 场景 | 模型 | 平台 | 原因 |
|------|------|------|------|
| 日常对话 | `deepseek-chat` | DeepSeek | 便宜、快 |
| 写代码 | `deepseek-coder` 或 `gpt-4o` | DeepSeek / OpenAI | 代码能力强 |
| 复杂推理 | `o1-mini` 或 `deepseek-reasoner` | OpenAI / DeepSeek | 推理专精 |
| 长文档总结 | `qwen-long` 或 `gemini-1.5-pro` | Qwen / Gemini | 100K+ 上下文 |
| 多模态（图像理解）| `gpt-4o` 或 `gemini-2.0-flash` | OpenAI / Gemini | 支持图片 |
| 中文写作 | `qwen-max` 或 `glm-4-plus` | Qwen / GLM | 中文强 |

**所有模型用同一个 base_url 和 api_key**，切换只改 model 名字。

## 八、用量统计查看

部署好之后，最有价值的事：

后台 → **用量查询** → 选择时间段

看到这样的报表：

```
模型           请求数     花费
gpt-4o-mini    1,234     $0.12
deepseek-chat  5,678     ¥0.34
qwen-plus      234       ¥0.05
---
合计                     ¥3.42
```

**根据用量调整策略**：
- 哪个模型用得多但效果不好 → 换便宜的
- 哪个平台经常 5xx → 加备用渠道
- 单日花费异常 → 查 token / 检查是否有脚本 bug

## 九、常见问题

### Q1: 客户端提示 "Invalid API Key"

**排查**：
1. Token 是否复制完整（前后无空格）？
2. Token 是否过期？
3. Token 是否在 New-API 后台被禁用？

### Q2: 客户端提示 "Model not found"

**原因**：New-API 里没配置该模型对应的渠道
**解决**：
- 后台添加该平台的渠道
- 或修改模型名

### Q3: 客户端提示 "Insufficient quota"

**原因**：对应平台余额不足
**解决**：去该平台充值，或切到其他渠道

### Q4: 速度慢

**优化**：
1. 后台 → 系统设置 → 启用**流式响应**
2. 给延迟低的平台更高权重
3. 启用**客户端缓存**（重复问题不重复扣费）
