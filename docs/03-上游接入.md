# 上游接入指南

> 配置 New-API 连接 OpenAI / Claude / DeepSeek / Qwen / GLM 等平台
> 让所有 token 用量汇总到 New-API Dashboard

---

## 接入前的准备

你需要：
1. 每个平台的账号（已有部分账号）
2. 每个平台的 API Key
3. 每个平台的余额（多数需要充值）

---

## 1. OpenAI

### 1.1 获取 API Key

1. 访问 https://platform.openai.com/api-keys
2. 登录（需要科学上网，建议用任务 2 搭的 VPS 访问）
3. 点 **+ Create new secret key**
4. 命名（如 `new-api`）→ **Create**
5. **复制 key**（格式：`sk-xxxxxxxx`，只显示一次）

### 1.2 充值

- 访问 https://platform.openai.com/account/billing
- **Add payment method** → 绑信用卡
- **Add to credit balance** → 充 $5 起

### 1.3 New-API 中配置

后台 → **渠道管理** → **添加渠道**

| 字段 | 填什么 |
|------|--------|
| 类型 | `OpenAI` |
| 名称 | `openai-primary` |
| 分组 | `default` |
| 模型 | （留空 = 全部支持）|
| **API Key** | `sk-xxxxxxxx` |
| 代理 | （留空，VPS 直连） |
| 优先级 | 0（数字小=优先）|
| 权重 | 10 |

点 **提交**。

### 1.4 验证

后台 → **Playground** → 选 `gpt-4o-mini` → 输入 `hi` → 发送
看到回复 = 成功 ✅

## 7. 接入后的配置技巧

### 7.1 多 Key 轮询（防爆刷）

每个平台可配置**多个 API Key**，New-API 会自动轮询：

后台 → 渠道管理 → 选渠道 → **添加新 Key**

### 7.2 模型重定向（省钱）

把贵的模型自动指向便宜的：

后台 → 系统设置 → **模型重定向**

| 原始模型 | 重定向到 |
|---------|---------|
| `gpt-4o` | `gpt-4o-mini` |
| `claude-sonnet-4.5` | `deepseek-chat` |

⚠️ 谨慎使用，会改变模型行为。

### 7.3 设置用户额度

后台 → 用户管理 → 选用户 → **设置额度**

每个用户的每月上限（防止意外爆刷）。

## 10. 常见问题

### Q1: 提示 "余额不足"

**解决**：去对应平台充值。

### Q2: 提示 "Invalid API Key"

**排查**：
1. 复制 Key 时多了空格？
2. Key 已被平台删除？
3. Key 权限不够？

### Q3: 请求超时

**原因**：上游平台在国外（OpenAI / Claude / Gemini），VPS 网络到上游慢
**解决**：
- 选延迟低的机房（日本比美国快）
- 升级 VPS 带宽
- 国内模型（DeepSeek/Qwen/GLM）不受影响

### Q4: 想要接入中转站（如 OpenRouter）

后台 → 添加渠道 → 类型选 `OpenAI 兼容` → 填 OpenRouter 的 API 地址和 Key
